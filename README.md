# GeoSense

> Explore. Understand. Simulate.

Hub full-stack de conhecimento em geociências, com visualização espacial, fontes rastreáveis e IA baseada em RAG para clima, sismologia, solo, vegetação, hidrologia e oceanografia.

## Princípios

- Nenhum dado fabricado: toda fonte externa deve ser documentada antes da integração.
- Observações e interpretações derivadas são apresentadas separadamente.
- Credenciais e chaves permanecem exclusivamente no ambiente de execução.
- A base começa pequena, testável e reproduzível; a estrutura evolui conforme dependências e testes comprovem a necessidade.

## Estado inicial

O repositório está sendo iniciado como um monorepo React + FastAPI. A fundação de desenvolvimento, ambiente Docker, observabilidade, testes e documentação será adicionada em mudanças incrementais e revisáveis.
